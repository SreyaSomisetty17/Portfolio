Oracle · Enterprise messaging platform

Eloqua SMS platform: event-driven messaging at scale

ProblemOracle's marketing-automation suite needed an SMS module that could sustain high daily volume with reliable, accurate delivery reporting, with no existing service to build on.
ApproachBuilt the module's Java microservices from scratch on the Helidon MP framework, using Kafka consumers for event-driven processing. Layered REST APIs across C# (.NET) and Java to handle the request load, with an automatic token-refresh mechanism for uninterrupted authentication, and designed the backend for a consolidated delivery-status view.
DecisionChose an event-driven pipeline over synchronous processing so the system could absorb spikes, and paired it with proactive observability rather than reactive support: dashboards that surfaced real-time data-propagation delays before they became incidents.
ResultA platform sustaining heavy daily throughput with materially fewer production incidents and faster recovery, backed by targeted database tuning.

ApproachBuilt a full-stack debugging platform for 50+ microservices that maps service dependencies and visualizes them, then layers AI agents over the logs and traces to correlate failures across services and point toward the likely cause.

San José State University · 2026

Distributed Coordination Layer (Chord DHT)

ProblemCoordinating work across edge and IoT nodes usually leans on a central coordinator, which is a single point of failure and a scaling bottleneck.
ApproachBuilt a decentralized, peer-to-peer coordination layer on a Chord distributed hash table. Nodes self-organize into a consistent-hash ring with O(log N) routing and no central authority, exposing task and job APIs over REST and gRPC.
DecisionMade fault tolerance first-class: k-successor replication with quorum writes and a self-healing stabilization protocol, plus AI-assisted job placement that falls back to a deterministic heuristic when needed.
ResultA resilient, self-healing system validated by a 71-test suite and deployed via Docker Compose on AWS EC2.
